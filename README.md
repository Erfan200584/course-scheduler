# 🎓 دستیار هوشمند انتخاب واحد (Course Scheduler)

یک وب‌اپلیکیشن سبک و سریع برای چیدمان خودکار و بدون تداخل برنامه‌های هفتگی دانشگاه. این برنامه مستقیماً فایل اکسل خروجی سامانه بهستان(گلستان) را دریافت کرده و تمام حالت‌های ممکن انتخاب واحد را به صورت بصری نمایش می‌دهد.

## ✨ ویژگی‌ها
* **پردازش کاملاً آفلاین (Client-side):** هیچ فایلی در سرور آپلود نمی‌شود و تمام پردازش‌ها درون مرورگر کاربر انجام می‌گیرد.
* **الگوریتم حل تداخل (Backtracking):** بررسی هوشمند تداخل ساعات کلاس و تاریخ امتحانات.
* **فیلتر جنسیت:** حذف خودکار گروه‌هایی که با جنسیت دانشجو تطابق ندارند.
* **پشتیبانی کامل از خروجی اکسل گلستان:** بدون نیاز به ویرایش دستی فایل‌ها.

## 🚀 نحوه استفاده
۱. یک خروجی اکسل از لیست دروس ارائه شده در سامانه بهستان(گلستان) دریافت کنید (یا از فایل `sample_data.xlsx` موجود در همین مخزن برای تست استفاده کنید).
۲. وارد لینک برنامه شوید.
۳. فایل اکسل را بارگذاری کرده و جنسیت خود را انتخاب کنید.
۴. دروس مورد نظر را جستجو و اضافه کنید.
۵. روی "ساخت همه‌ی چیدمان‌ها" کلیک کنید تا برنامه‌های بدون تداخل را در یک تقویم هفتگی ببینید.

## 🛠 تکنولوژی‌های استفاده شده
* HTML / CSS (Vanilla)
* JavaScript
* کتابخانه `SheetJS` برای پردازش فایل‌های اکسل
